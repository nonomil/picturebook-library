🔊 翘舌音拼读

zh / ch / sh / r + 韵母 → 音节

zh + a = zhā zh (知) + a (啊) → 一声 zhā 🐷 扎辫子 zhā biàn zi
zh + e = zhè zh + e (四声) → zhè 👉 这个 zhè ge
zh + u = zhū zh + u (一声) → zhū 🐷 小猪 xiǎo zhū
ch + i = chī ch + i (一声) → chī 🍚 吃饭 chī fàn
sh + a = shā sh + a (一声) → shā 🏖️ 沙子 shā zi
r + e = rè r + e (四声) → rè 🔥 热天 rè tiān
zhā (扎) chē (车) shū (书) rì (日)
拼读练习 · 2/3

🔊 平舌音拼读

z / c / s + 韵母 → 音节

z + a = zá z (资) + a (二声) → zá 📚 杂志 zá zhì
z + u = zú z + u (二声) → zú ⚽ 足球 zú qiú
c + a = cā c + a (一声) → cā 🧽 擦桌子 cā zhuō zi
c + u = cū c + u (一声) → cū 🌳 粗大 cū dà
s + a = sǎ s + a (三声) → sǎ 💧 洒水 sǎ shuǐ
s + u = sù s + u (四声) → sù 🚀 速度 sù dù
zū (租) cā (擦) sǎ (洒) zǔ (组)
拼读练习 · 3/3

🔊 头母 y w 拼读

y w 是特殊声母（半元音）

📌 规则：y 后面跟 ü 时，ü 上两点要省略，写成 yu。比如 y + ü → yú (鱼)，不是 yǘ。

y + a = yā y (一) + a (啊) → yā 🦆 鸭子 yā zi
y + e = yè y + e (四声) → yè 🍃 叶子 yè zi
y + ü = yú y + ü → yú · ü 上两点省略 ✨ 🐟 小鱼 xiǎo yú
w + a = wā w (屋) + a (一声) → wā 🐸 青蛙 qīng wā
w + o = wǒ w + o (三声) → wǒ 👤 我 wǒ
w + u = wū w + u (一声) → wū 🏠 房屋 fáng wū

🎯 复合韵母拼读

ch + ao chǎo (吵) 🗣️ 吵闹
sh + ui shuǐ (水) 💧 水
r + ou ròu (肉) 🥩 肉
c + ai cài (菜) 🥬 蔬菜
s + ao sǎo (扫) 🧹 扫地
