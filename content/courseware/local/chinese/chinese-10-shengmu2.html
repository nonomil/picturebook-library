声母 j · q · x
👅 舌面音

舌面抬起贴近上颚，轻轻摩擦发音！
j 不送气，像小鸡啄米
q 送气，像气球放气
x 像微笑时轻轻吹气

声母 zh · ch · sh
👅 翘舌音

舌尖卷起抵住硬腭前部，像在说英文 "j"！
zh 不送气，卷舌轻弹
ch 送气，卷舌吹气
sh 卷舌摩擦，像"狮"吼

声母 r · z · c
👅 翘舌 + 平舌音

r 翘舌浊音，像"日"出温暖
z 平舌不送气，像"字"正腔圆
c 平舌送气，像"刺"出尖锐

👅 平舌 + 半元音

s 平舌擦音，像蛇吐信子

🧩 拼读乐园 · j q x
🧩 j q x + i = 拼音

声母 j q x 和 i 拼在一起，注意：j q x 只与 i、ü 开头的韵母相拼！
例如 j + i = jī（鸡）· q + i = qì（气）· x + i = xī（西）
