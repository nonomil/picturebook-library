# 课件模板目录

这里是统一课件模板的实现预留目录。模板先按“儿童使用任务”划分，再接入现有课件内容：

- `adventure-story/`：连续故事、绘本、双语故事和探索剧情。
- `interactive-classroom/`：语文、英语、数学等有明确知识步骤的课程。
- `activity-studio/`：儿歌、科学、机械、手工、生活技能和开放活动。

模板实现和内容数据保持分离：历史课件保留在 `content/courseware/local/`，新模板试点位于各自的 `pilots/` 目录。模板只负责离线阅读、练习和完成记录，不把某一本课件的文字、图片或积分逻辑写死在模板里。

每个模板必须满足：

1. 可在无网络环境打开，不能依赖 CDN、远程字体或远程音频。
2. 移动端和桌面端都有清晰的当前步骤、返回和下一步操作。
3. 发音失败时提供离线 TTS 或可理解的提示，不得假装播放成功。
4. 完成事件只能由统一完成状态首次写入本机台账时触发一次；课件默认不修改绘本首读奖励或宠物积分账本。
5. 迁移前后保留原始课件 ID，便于内容审计和回归定位。
