# 互动课堂模板

## 适用内容

语文、拼音、识字、英语主题词汇、数学概念、练习和阶段复习等有明确教学目标的课程。

## 页面结构

1. **课程封面**：课程目标、适龄、预计时长和“开始挑战”。
2. **学习路线**：认识、示范、一起做、自己试、复习五类步骤；短课可合并步骤。
3. **内容页**：一个核心概念 + 一组示例 + 一个主要操作。
4. **练习页**：选择、配对、排序、点击、朗读或填写，反馈必须在当前页可见。
5. **复习页**：错题/易错点重新出现，允许重试，不用失败阻断整节课。
6. **完成页**：完成度、掌握点、下一节推荐和本机完成反馈。

## 内容字段

```text
id, title, subject, level, objectives[], duration
steps[].type, steps[].title, steps[].body, steps[].image, steps[].audio
steps[].interaction, steps[].options, steps[].answer, steps[].hint
review[], completionFeedback, sourcePath
```

## 必须状态

- `intro`、`learn`、`practice`、`review`、`completed`。
- 顶部显示当前步骤/总步骤，底部保持大尺寸上一页、朗读、检查、下一页。
- 检查后必须显示正确、需要再试或查看提示，不能只有颜色变化。
- 练习失败允许重试；完成事件只能在课程达到完成条件后首次写入本机台账时产生一次。

## 视觉规则

- 每页只放一个知识重点，长练习拆为多张卡片。
- 语文使用笔画/拼音可视化，英语使用词卡和跟读波纹，数学使用可操作的数量/图形对象。
- 页面背景可以按学科变化，但内容卡、按钮、进度、反馈组件保持同一套尺寸和间距。
- 桌面端允许左侧步骤列表；移动端改为顶部进度轨迹，避免挤压内容区。

## 迁移验收

- 逐页确认标题、例题、答案、提示和图片语义。
- 至少操作一次每种练习类型，确认反馈、重试和完成状态。
- 朗读按钮能识别当前页主要文本，离线资源缺失时有可见降级。
- 320px 宽度无横向滚动，桌面端内容不被固定导航遮挡。
